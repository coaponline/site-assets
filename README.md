# COAP Online site assets

Public files for coaponline.com's pages: the shared styles (`site.css`), the shared script (`site.js`), each page's own
styles and script (`pages/`), and the photographs (`assets/`). Served by GitHub Pages and loaded by the Kajabi pages.

Nothing private lives here: only what a visitor's browser downloads anyway. Built from the site mock by
`Academy 2027/kajabi-build/` in the COAP ops repo.
